# Frontend-Kavana

Ini adalah repositori untuk **Frontend UI/UX** dari aplikasi Kavana.
Fungsi utama dari direktori ini adalah:
1. Menyediakan antarmuka pengguna (User Interface) yang interaktif dan responsif berbasis React/Next.js.
2. Menghubungkan pengguna dengan fitur-fitur aplikasi (dashboard, manajemen tugas, proses akademik).
3. Mengelola state aplikasi dan melakukan fetching data ke Backend API.
4. Mendukung berbagai hak akses (role-based interface) seperti mahasiswa, dosen, kaprodi, dan admin.

Semua dokumentasi terkait komponen UI, panduan testing, dan audit UX telah dipindahkan ke dalam folder `Docs-Kavana/Frontend-Kavana`.
